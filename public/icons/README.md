# Toolkit icons

These selected SVG assets are served locally; no external icon service or runtime package is required.

- [Devicon](https://github.com/devicons/devicon), MIT: Flutter, React, Ionic, HTML5, CSS3, Node.js, FastAPI, Firebase, OAuth, Python, JavaScript, Java, C#, C++, Lua, Visual Basic, Arduino, Git, GitHub, Linux, DigitalOcean, PM2, Vercel, and Google Cloud. Original variants are used except Linux, which uses the smaller plain variant. License: `Devicon-LICENSE.txt`.
- [Simple Icons](https://github.com/simple-icons/simple-icons), CC0: PWA, MediaPipe, Espressif, Google Maps, and Google Play. License: `Simple-Icons-LICENSE.txt`.

Logos identify the named technologies. Selected monochrome logos are displayed in a light color for contrast against the dark theme. Skills without a distinct product logo use local, descriptive SVG symbols from `src/components/Icon.jsx`; mappings are in `src/data/skillIcons.js`.
